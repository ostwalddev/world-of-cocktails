# World of Cocktails

A blank Next.js app using React, TypeScript, the App Router, and ESLint.

## Getting started

Use Node.js 20.9 or newer and pnpm 11.25.0.

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000. Edit `src/app/page.tsx` to start building.

## Checks and production

```sh
pnpm lint
pnpm exec tsc --noEmit
pnpm build
pnpm start
```
